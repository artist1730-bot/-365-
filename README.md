# AIN365 - 아인병원 시설관리 통합시스템

## 📋 프로젝트 개요

**AIN365**는 아인병원 시설관리팀을 위한 웹 기반 통합관리 시스템입니다. 단일 HTML 파일로 구성되어 있으며, 구글 시트와 연동하여 실시간 데이터 관리가 가능합니다.

## ✨ 주요 기능

### 1. 메인 페이지 (홈)
- 시스템 소개 및 주요 기능 안내
- 직관적인 UI로 빠른 접근성 제공
- 4가지 핵심 기능 소개 카드

### 2. 대시보드
- **실시간 통계 카드**: 총 점검 항목, 정상, 주의, 긴급 상태 현황
- **점검 상태 현황 차트**: Doughnut 차트로 상태 분포 시각화
- **월별 점검 추이 차트**: Line 차트로 12개월 추세 분석
- **카테고리별 현황 차트**: Bar 차트로 점검 항목별 건수 표시

### 3. 데이터 테이블 (4개 섹션)
- **시설 점검 현황**: 시설별 점검 항목 및 상태 관리
- **유지보수 내역**: 일자별 작업 내용 및 비용 관리
- **안전점검 현황**: 안전점검 구분별 결과 추적
- **설비 관리**: 주요 설비 상태 및 점검 일정 관리

### 4. 검색 및 필터링
- 각 테이블마다 실시간 검색 기능
- Enter 키 또는 검색 버튼으로 실행
- 모든 컬럼에 대한 통합 검색 지원

### 5. 반응형 디자인
- **데스크톱**: 최대 1400px 너비 최적화
- **태블릿**: 768px~1024px 레이아웃 조정
- **모바일**: 480px 이하 완전 최적화
- 터치 친화적 UI 요소

## 🔗 구글 시트 연동 설정

### 단계 1: 구글 시트 준비
1. 제공하신 4개의 구글 시트를 준비합니다
2. 각 시트의 첫 번째 행에 헤더(컬럼명)가 있어야 합니다

### 단계 2: 웹에 게시
1. 각 구글 시트를 엽니다
2. **파일 > 공유 > 웹에 게시** 클릭
3. 게시 옵션:
   - 게시 대상: 해당 시트 선택
   - 형식: **CSV**
4. **게시** 버튼 클릭
5. 생성된 URL 복사

### 단계 3: HTML 파일 수정
`index.html` 파일의 **40번째 줄 근처**에서 다음 설정을 찾아 수정:

```javascript
const GOOGLE_SHEETS_CONFIG = {
    sheet1: 'YOUR_SHEET1_CSV_URL_HERE', // 시설 점검 현황
    sheet2: 'YOUR_SHEET2_CSV_URL_HERE', // 유지보수 내역
    sheet3: 'YOUR_SHEET3_CSV_URL_HERE', // 안전점검 현황
    sheet4: 'YOUR_SHEET4_CSV_URL_HERE'  // 설비 관리
};
```

### 단계 4: 데이터 형식
각 시트는 다음과 같은 형식을 권장합니다:

**시트1 - 시설 점검 현황**
```
id, 시설명, 점검항목, 상태, 점검일, 담당자
1, 1층 로비, 조명, 정상, 2024-01-15, 김철수
```

**시트2 - 유지보수 내역**
```
id, 일자, 위치, 작업내용, 비용, 업체
1, 2024-01-15, 2층 병동, 소방설비 점검, 150,000, ABC소방
```

**시트3 - 안전점검 현황**
```
id, 점검구분, 위치, 결과, 점검일, 비고
1, 화재예방, 전층, 양호, 2024-01-15, 정기점검
```

**시트4 - 설비 관리**
```
id, 설비명, 위치, 상태, 다음점검일, 담당업체
1, MRI 장비, 3층 영상의학과, 정상, 2024-02-15, 지멘스
```

## 📱 주요 기능 설명

### 실시간 시계
- 헤더에 현재 시간 표시 (1초마다 업데이트)
- 한국 시간대 기준 (YYYY-MM-DD HH:mm:ss)

### 데이터 새로고침
- 헤더의 "데이터 새로고침" 버튼
- 모든 데이터를 다시 로드
- 로딩 중 애니메이션 표시

### 탭 네비게이션
- 6개 탭으로 구성:
  1. 홈
  2. 대시보드
  3. 시설 점검 현황
  4. 유지보수 내역
  5. 안전점검 현황
  6. 설비 관리
- 선택된 탭 하이라이트
- 부드러운 페이드인 애니메이션

### 상태 표시
- **정상**: 녹색 배지
- **주의**: 주황색 배지
- **긴급**: 빨간색 배지
- **양호/보통/불량**: 결과에 따른 색상 구분

## 🚀 사용 방법

### 1. 기본 실행
1. `index.html` 파일을 웹 브라우저에서 엽니다
2. 현재는 데모 데이터로 작동합니다
3. 모든 기능을 테스트할 수 있습니다

### 2. 구글 시트 연동 후
1. 위의 "구글 시트 연동 설정" 단계를 완료합니다
2. 파일을 저장하고 새로고침합니다
3. 자동으로 구글 시트의 실제 데이터가 로드됩니다

### 3. 데이터 업데이트
1. 구글 시트에서 데이터를 수정합니다
2. 시스템의 "데이터 새로고침" 버튼을 클릭합니다
3. 최신 데이터가 반영됩니다

## 🔧 커스터마이징

### 색상 변경
CSS 변수를 수정하여 전체 색상 테마를 변경할 수 있습니다 (`index.html` 파일 내):

```css
:root {
    --primary-color: #2563eb;      /* 메인 색상 */
    --secondary-color: #1e40af;    /* 보조 색상 */
    --success-color: #10b981;      /* 성공/정상 */
    --warning-color: #f59e0b;      /* 경고/주의 */
    --danger-color: #ef4444;       /* 위험/긴급 */
    /* ... 기타 색상 변수 */
}
```

### 폰트 변경
Google Fonts에서 다른 한글 폰트를 선택하여 변경 가능:

```html
<link href="https://fonts.googleapis.com/css2?family=다른폰트명&display=swap" rel="stylesheet">
```
